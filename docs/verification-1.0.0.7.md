# 1.0.0.7 验证记录

日期：2026-11-17（Asia/Shanghai）。本版新增每台打印机的 Apple 显示名称，并调整 WinUI 界面对齐。

## 名称与兼容性

- 在原有 `SharedPrinter` 设置中增加可选 `displayName`；设置版本保持 1，旧版配置缺少该字段时自动使用 `打印机名称- CX Printer`。
- 自定义名称保存时去掉首尾空白；留空或“恢复默认”会保存为 `null`。不修改 Windows 队列名称、打印机 ID、UUID 或 IPP 路径。
- Bonjour 实例名与 IPP `printer-name`、`printer-info` 共用同一计算结果。自定义名称按单个 DNS 标签传入，中文、emoji、点号和反斜杠经过真实 DNS 报文往返后保持一致。
- 限制为 63 个 UTF-8 字节；验证 63 字节英文和 21 个汉字边界，拒绝超长名称及控制字符，拒绝同一配置中的重名。过长默认名称按完整 Unicode 字符缩短，保留区分标识和 `- CX Printer` 后缀。
- 保留 1.0.0.6 的稳定 `cx-<主机标识>.local` SRV 目标及匹配的 A/AAAA 地址，改名不会影响 Mac 构造 IPP URI。

## 自动检查

- 核心协议测试 **19/19 通过**。
- 后台集成测试 **31/31 通过**。
- 新增真实 HTTP 回归验证：保存自定义名称、重新读取设置、触发配置变更通知、IPP 返回新名称、DNS-SD/IPP 名称一致、非法名称不会覆盖已有设置、恢复默认名称。
- 原有 Mac SRV URI、纸张尺寸、认证、作业处理及渲染测试继续通过。
- 自动测试使用临时设置与模拟打印后端，不安装系统服务、不修改防火墙、不向实体打印机发送任务。

## 界面调整

- 统一卡片标题字号、内容边距、表单宽度和按钮高度。
- 打印机列表复选框采用固定宽度列，文字左对齐；列表中显示 Apple 名称预览。
- 选中可用打印机后可编辑名称、恢复默认、设置默认纸张；全部纸张尺寸收进展开区。
- 切换页面回到页首；刷新列表时保留尚未保存的名称与纸张设置。
- 汉堡菜单折叠时隐藏侧栏底部服务状态及设备说明，展开后恢复。
- 如果独立安装的后台尚未更新至 1.0.0.7，保存前提示更新，避免旧后台忽略新名称字段。

1.0.0.6 的 Mac 添加修复已由用户在实际环境确认成功；本版新增名称功能的 Apple 设备端显示尚待实际环境确认。
