# CX Printer 1.0.0.8

本版让共享打印机通过 IPP 提供 Windows 驱动可读取的墨水、碳粉等耗材信息，并重写项目首页与安装、开发文档。

## 新增耗材读取与上报

- 使用 Windows 标准双向通信接口读取耗材种类、颜色、型号、安装状态和百分比，USB 与网络队列均取决于驱动支持。
- “打印机共享”页选中打印机后显示耗材信息；复制诊断信息时附带读取状态。
- 提供 macOS/CUPS 使用的 `marker-*` 和标准 IPP `printer-supply` 属性，支持耗材名称、颜色、余量和状态查询。
- 提供低余量、耗尽、废料盒接近装满或已满的警告；未知、未安装和无效数据不会伪装成 0% 或 100%。
- 后台约每分钟更新，读取与纸张能力扫描独立。最多两个查询并行；同一队列尚未结束的读取不会重复启动。两分钟未更新的数据停止上报。

Mac 的具体显示取决于 macOS 版本；iPhone/iPad 的系统打印界面未必展示耗材百分比。仅厂商私有工具能读取的数据目前未接入，实体设备端展示仍需实机验证。详细条件见 [耗材支持说明](supplies.md)。

## 安装与升级

发布包：`CX-Printer_1.0.0.8_x64.msix`，适用于 Windows 10 1809 / build 17763 及以上的 x64 系统，附带所需运行时。

首次安装先信任随包的 `MasterTea.cer`。从旧版更新时直接安装 MSIX，然后在“启动与连接”点击一次“修复服务与防火墙”，确认后台版本为 `1.0.0.8`。共享选择、显示名称、默认纸张和认证设置会保留。

选中实体打印机，等待约一分钟即可查看驱动返回的耗材信息。无法读取时按界面提示检查双向支持和厂商驱动。

## 验证范围

源码检查已通过核心协议测试 **21/21** 和后台集成测试 **37/37**，涵盖耗材 XML、未知与无效值、原生 Windows COM 退化处理、缓存过期、慢查询、删除后重加队列、真实 HTTP 属性返回，以及原有打印和设备发现回归。

发布时另校验 MSIX 内容、签名、文件哈希及应用安装入口；机器可读报告随 Release 附件提供。本机没有实体打印机或 Apple 设备，耗材端到端显示与物理出纸未在本机验证。
