## 更新内容

- 发现广播的固定说明改用 ASCII 连字符，避免纯英文打印机与主机名也因程序内部中点触发 ASCII 编码失败；中文等本地化 TXT 值继续使用 UTF-8。
- 加入纯英文打印机与主机名的完整 DNS-SD 公告、PTR/SRV/TXT 查询、报文编解码和撤销回归。
- 明确升级管理端后应执行“修复服务与防火墙”，以同步独立安装的后台服务。

版本 **1.0.0.5（x64）**，最低 **Windows 10 1809 / build 17763**，发布者与签名为 **MasterTea**。

## 更新步骤

1. 安装 `CX-Printer_1.0.0.5_x64.msix`，可直接覆盖旧版。首次安装需按 `Installation.md` 信任公开证书 `MasterTea.cer`。
2. 打开“启动与连接”，点击“修复服务与防火墙”。该步骤会同步后台二进制并保留打印机选择及认证设置。
3. 确认发现状态显示“已广播 … 台打印机”。如果仍有错误，复制诊断信息供排查；再在 Mac 中移除并重新添加打印机。

完整服务回归测试在当前构建环境被临时目录访问拒绝阻断，本次不报告该套件通过。未连接实体 Mac 或打印机；真实设备发现与出纸需在目标环境确认。
