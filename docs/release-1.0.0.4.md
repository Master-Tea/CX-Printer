## 更新内容

- 新增最小化到系统托盘；双击图标恢复主窗口，右键显示窗口或退出。
- 补齐浅色、深色主题与各尺寸的透明无底板图标，移除 Windows 自动添加的主题色背景。
- 打印机先显示名称，再后台逐台读取纸张能力；显示当前队列与耗时，缓存结果，减少刷新与安装前后的重复等待。
- 服务安装/修复隐藏控制台，显示真实阶段、文件数量、进度和耗时；安装后保留打印机列表。
- 修复 DNS-SD 文本字段中的 `Only ASCII characters are allowed`，中文和中点等字符使用 UTF-8 广播。
- 保留 Microsoft Print to PDF 为共享测试队列，自动生成 `%ProgramData%\CX Printer\TestOutput` 中的 PDF，不弹出另存为窗口；打印记录提示输出位置。

版本 **1.0.0.4（x64）**，最低 **Windows 10 1809 / build 17763**，发布者与签名仍为 **MasterTea**。

## 更新步骤

1. 安装 `CX-Printer_1.0.0.4_x64.msix`，可直接覆盖旧版。首次安装需按 `Installation.md` 信任公开证书 `MasterTea.cer`。
2. 打开“启动与连接”，点击一次“修复服务与防火墙”，将新版后台同步到系统服务，已有共享和认证设置会保留。
3. 如 Mac 缓存了旧队列，请删除后重新添加；可先共享 Microsoft Print to PDF 做测试。
